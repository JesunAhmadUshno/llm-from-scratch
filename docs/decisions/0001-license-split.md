# 0001. Code under Apache-2.0, tutorials under CC BY 4.0

Date: 2026-11-04. Status: accepted (ruling D-V3-11).

Context: the repo holds both runnable code and teaching text
(fanout/tutorial.md, the level READMEs).

Decision: code is Apache-2.0 (LICENSE); tutorials are CC BY 4.0.

Consequences: anyone may reuse the code with the patent grant of
Apache-2.0, and the teaching text with attribution. Changing either
licence later needs every contributor's consent, so it is recorded here.
